Pipeline

先定畫面，再做動態Frame first, motion second

GPT Image 2 負責決定畫面長什麼樣：角色、構圖、格數、文字與視覺一致性。Seedance 2 負責讓畫面動起來：時間軸、運鏡、物理、轉場與聲音提示。GPT Image 2 decides what the frame looks like: character, composition, panel layout, text, and visual consistency. Seedance 2 decides how that frame moves: timeline, camera motion, physics, transitions, and sound cues.

最穩的流程不是「一句話直接生影片」，而是先把導演意圖變成幾張清楚的圖。圖片越清楚，影片模型需要自由發揮的地方就越少。The most reliable workflow is not one sentence straight to video. First turn the directing intent into clear images. The clearer the images, the less the video model has to invent.

  • 想快速找風格：先用 Nano Banana 或 GPT Image 2 做 mood / style exploration。For fast visual exploration, start with Nano Banana or GPT Image 2 mood/style exploration.
  • 想做短片：先生成 storyboard grid，再餵給 Seedance。For short films, generate a storyboard grid first, then feed it to Seedance.
  • 想保角色：先做 character sheet，再把它指定為 Image 2。For character consistency, create a character sheet and assign it as Image 2.
Pre-production

從劇本到影片的資料順序From script to usable video references

前製文件不是越多越好，而是每一份都要鎖定一種變數。先把人物、場景、情緒、鏡頭順序拆開，最後再交給 Seedance 組成動態，成片會穩很多。Pre-production is useful when each document locks one variable. Separate character, location, mood, and shot order before asking Seedance to animate them.

Shot Language

常用鏡頭語言怎麼寫Writing practical shot language

不要只丟專有名詞。比較穩的寫法是「鏡頭類型 + 畫面重點 + 情緒目的」，讓模型知道這個鏡頭為什麼存在。Do not rely on jargon alone. Use shot type + visual focus + emotional purpose so the model knows why the shot exists.

EWS / WS建立空間、地理關係、角色在環境中的比例。Establish space, geography, and character scale.
MS / MCU適合對話、動作準備、角色與背景同時可讀。Good for dialogue, action setup, and readable character-background balance.

Timeline

15 秒 Seedance 時間軸範本A 15-second Seedance timeline pattern

Seedance 最怕文字一次塞太多動作。可以用 6 段時間軸，每段只寫一個主要動作、一個鏡頭運動，以及必要的物理細節。Seedance becomes unstable when too many actions are packed together. Use six timed beats with one main action, one camera move, and necessary physical detail per beat.

時間Time功能Function
0-2s建立場景與角色位置，動作不要太大。Establish scene and character position.
2-5s主要動作開始，鏡頭跟上但不要亂切。Begin the main action with a controlled camera move.
5-8s動作升級或角色反應，保留清楚方向。Escalate action or show reaction while preserving direction.
8-11s放大細節、慢動作、物件或表情轉折。Highlight detail, slow motion, object, or expression shift.
11-13s完成動作，讓畫面回到可剪接的穩定狀態。Resolve the action into an editable stable frame.
13-15s停在最後畫面，方便接下一顆鏡頭。Hold a final frame for the next shot.
Storyboard

格數怎麼選Choosing panel count

格數不是越多越好。短影片需要的是清楚的節奏，而不是把所有細節塞進同一張圖。每格最好只負責一個主要動作或一個情緒轉折。More panels are not always better. Short videos need clear rhythm, not every detail packed into one image. Each panel should carry one main action or emotional turn.

Before Prompting

做圖前先準備什麼What to prepare before prompting

不要一開始就把故事丟給影片模型。先把「角色長相、場景、關鍵道具、鏡頭順序」拆成可以被看懂的參考圖，影片生成會穩定很多。Do not send the whole story straight to the video model. First turn character identity, environment, key props, and shot order into visual references the model can read.

  • 角色：先做 character sheet，包含正面、側面、背面、表情與動作姿勢。Character: create a character sheet with front, side, back, expressions, and action poses.
  • 場景：先做空場景或環境參考，鎖定光線、色調、材質與空間方向。Environment: create a clean scene reference to lock lighting, color, texture, and spatial direction.
  • 道具 / 商品：單獨做參考圖，並寫清楚 logo、形狀、材質與顏色不能改。Prop/product: create a separate reference and specify that logo, shape, material, and color must not change.
  • 分鏡：每格只放一個主要動作，讓 Seedance 能照順序理解。Storyboard: keep one main action per panel so Seedance can follow the order.

Seedance

Seedance prompt 必備三件事Three essentials for Seedance prompts

Seedance 不是只看文字，它會依照你指定的參考圖理解角色、場景與順序。Prompt 的重點是把每張圖的用途說清楚，並把影片拆成時間段。Seedance does not only read text; it uses the reference images to understand character, scene, and order. The prompt should define each image role and break the video into timed beats.

  • 指定參考圖用途：Image 1 = storyboard，Image 2 = character，Image 3 = environment，Image 4 = product/prop。Assign reference image roles: Image 1 = storyboard, Image 2 = character, Image 3 = environment, Image 4 = product/prop.
  • 寫時間軸：0–2s、2–4s、4–6s，每段只放一個主要動作。Write a timeline: 0–2s, 2–4s, 4–6s; keep one main action per beat.
  • 結尾加一致性與禁止事項：不要變臉、不要換衣服、不要亂加角色、不要 flicker / morphing。End with consistency and negative rules: no face drift, outfit changes, unrelated characters, flicker, or morphing.
Continuity

180 度線要講成可視化規則Make the 180-degree line visual

不要只寫「遵守 180 度線」。要明確寫：A 在畫面左側、B 在畫面右側、A 看右、B 看左、攝影機不越過對話軸線。Do not only write "follow the 180-degree rule." Spell it out: A stays screen left, B stays screen right, A looks right, B looks left, camera never crosses the dialogue axis.

Checklist

輸出前快速檢查Pre-output checklist

如果生成結果不穩，通常不是模型完全不懂，而是 prompt 沒有鎖住它最容易亂補的地方：角色、時間順序、鏡頭方向、道具與場景連續性。When results are unstable, the model often understands the idea but the prompt did not lock the parts it tends to invent: identity, time order, screen direction, props, and scene continuity.

  • 每張參考圖是否有明確用途？不要只寫 use the images。Does each reference image have a clear role? Do not only write "use the images."
  • 每格是否只有一個主要動作？太多動作會讓影片模型亂補。Does each panel contain one main action? Too many actions invite random motion.
  • 是否有寫角色、服裝、產品、場景不能變？Did you lock character, outfit, product, and scene consistency?
  • Seedance 是否有時間軸？沒有時間軸通常會變成自由發揮。Does the Seedance prompt include a timeline? Without one, motion becomes too free.
  • 如果是對話，是否有寫畫面左右與視線方向？For dialogue, did you define screen side and eyelines?
